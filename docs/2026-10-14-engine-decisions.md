# 2026-10-14 릴스 엔진 확정값

- 실사 숙소 사진은 시설과 레이아웃을 사실로 증명하는 앵커로 사용한다. 대본의 감정과 동선을 전달하는 장면은 1인칭 AI 이미지가 주력이며, 보통 전체 20컷의 60~80%를 차지한다.
- 영상 생성은 원본 구조와 물체를 고정하고, 느린 카메라 이동과 기존 잎의 미세한 움직임만 허용한다.
- 컷은 보통 1~2초이며 강한 첫 장면은 후반에 한 번 콜백할 수 있다.
- 대본은 숙소명을 말하지 않고, 직접 댓글 CTA 없이 실제 다녀온 사람의 경험형 결론으로 끝낸다.
- 대본을 먼저 억지로 끊지 않는다. 전체 문장 흐름을 완성한 뒤 각 영상 컷에 짧게 배분한다.
- Typecast 한영 보이스를 사용한다. 보이스 ID와 API 키는 환경변수로만 전달한다.
- Typecast 글자별 타임스탬프를 기준으로 자막과 영상 컷을 같은 순간에 전환한다.
- 기본 영상 동작 속도는 1.2배다.
- 자막은 Noto Serif KR, 흰색, 화면 중앙보다 조금 위, 얇은 외곽선과 넓고 부드러운 검은 그림자를 사용한다.
- 우측 상단에 작은 `[광고]`를 전체 구간 표시한다.
- 사진·영상·TTS 결과물과 API 키는 공개 Git 저장소에 커밋하지 않는다.
