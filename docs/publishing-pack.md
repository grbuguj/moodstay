# 최종 게시 패키지 기준

영상 렌더와 게시물 운영은 다른 단계다. 최종 납품에는 아래를 분리해 제공한다.

1. `final_reel.mp4` — 1080×1920, 자막과 TTS가 편집된 영상.
2. `thumbnail.png` — 첫 장면을 배경으로 한 9:16 썸네일. 카피는 사용자 선택 문구만 사용한다.
3. `captions.srt` — 수정·재활용용 자막 파일.
4. `posting.md` — 캡션, 필요한 제휴/광고 고지, 해시태그, 운영 문구.

## 썸네일 선택 흐름

- `V01`이 잠기면 에이전트가 카피 후보 정확히 5개를 낸다.
- 사용자가 한 개를 선택한다. 임의 선택은 금지다.
- 영상 QA 후, 선택된 카피로 실제 썸네일 PNG를 만든다.
- 스타일: 9:16, 텍스트 블록의 중심점이 캔버스 정중앙, 초굵은 흰색 한글과 두꺼운 검정 외곽선/그림자, 우측 상단 `[광고]`.

## BGM

저작권이 있는 음원을 자동으로 렌더에 넣지 않는다. 사용자는 라이선스 보유 음원을 제공하거나, 완성 MP4를 업로드한 뒤 Instagram 내에서 트렌딩 오디오를 추가한다. 선택과 음원명은 `posting.md`에 기록한다.
