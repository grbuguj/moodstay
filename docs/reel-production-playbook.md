# 숙소 릴스 제작 플레이북

## 계정 톤

- 여행을 잘 아는 여성이 조용히 알려주는 느낌의 큐레이션.
- 광고 문구나 객실 설명 나열보다, 직접 다녀온 듯한 발견과 감정을 먼저 둔다.
- TTS는 편안하지만 속도감 있는 여성 목소리를 기준으로 문장을 짧게 끊는다.

## 수익화 흐름

릴스에서 숙소명을 감춘 뒤, 궁금증을 만든다. 댓글 키워드는 별도 운영 단계에서 사용하며 대본 본문에 자동으로 삽입하지 않는다. 링크 전달과 제휴 고지는 댓글·DM 운영 문구에서 별도로 관리한다.

## 대본 구조

1. 첫 문장: 장소 정체를 뒤집는 한 줄 훅.
2. 시각 증명: 훅을 보여주는 풍경을 바로 이어 붙인다.
3. 반전: 예쁜 풍경 외에 실제로 편리한 객실/시설을 보여준다.
4. 하루 동선: 낮–저녁–밤의 체험으로 체류 장면을 만든다.
5. 추천 대상: 가족, 친구, 커플 등 한 문장으로 마무리한다.

## 영상 원칙

- 최종 이미지와 영상은 9:16, 기본 1080×1920.
- 자막이 바뀔 때마다 영상 소스도 바꾼다. 동일 이미지를 단순 확대·크롭해 재사용하지 않는다.
- 프롬프트는 카메라 움직임만 최소한으로 지시한다. 건물, 가구, 인물, 풍경을 새로 만들거나 왜곡하지 않는다.
- 이미지 원본에 텍스트, 로고, 워터마크가 있으면 제외한다.
- 첫 컷은 정지 상태 약 0.3초 후 훅 자막을 띄운다.

## 썸네일 규칙

- 세로 9:16.
- 제목 블록은 화면 정중앙(가로·세로 모두 중앙).
- 초굵은 흰색 한글 + 두꺼운 검정 외곽선/그림자.
- 우측 상단에 `[광고]`.
- 이미지보다 훅 문장이 우선이다.
