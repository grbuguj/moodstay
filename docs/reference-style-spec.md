# 레퍼런스 측정과 제작 데이터 구조

분석일: 2026-10-13. 원본: https://www.instagram.com/reel/DbfkzFrBIKN/
실제 작성자는 `ohayo.to_travel`이다. `heo.jinny.gogo` 계정 조사는 운영 참고이고 이 영상의 작성자 확인과 구분한다.

이 문서는 기존 플레이북을 묵시적으로 덮어쓰지 않는다. 관측 사실과 제작 제안을 분리해서 이후 구현의 근거로 사용한다.

## 관측값

- 확보한 공개 버전: 720×1280, 30fps, 영상 616프레임 / 20.533초.
- 컨테이너 20.663초. 영상 길이와 오디오 끝의 차이를 보존해 기록한다.
- 시각적 장면 17구간, 하드 컷 16회. 평균 1.208초, 중앙값 1.267초, 최소 0.700초, 최대 1.700초.
- 장면 시작 프레임: `0,37,73,101,152,175,200,245,268,317,358,397,441,479,521,552,573`. 마지막 프레임은 615이며 끝점은 616이다.
- 첫 0번 프레임만 큰 커버 제목이다. 1번부터 작은 본문 자막을 사용한다.
- 본문 자막 18구간. 시작 프레임: `1,37,73,101,152,175,200,245,268,291,317,358,397,441,479,521,552,573`.
- 291번 프레임의 자막 전환은 영상 전환 없이 이루어진다.
- 본문 자막 중앙 좌표는 대략 `(0.5W, 0.50H)`, 계정 표식은 `(0.5W, 0.75H)`. 정확한 폰트는 미확인이다.
- 전체 믹스 음량 -14.22 LUFS, 트루 피크 -3.08 dBTP, LRA 1.40 LU. TTS 제공사·음성 이름·BGM BPM·단어별 음성 정렬은 미확인이다.

## 이야기의 역할

1. 시청자 상황과 짧은 추천: 0.033–2.433초.
2. 지역과 특이한 숙소 콘셉트: 2.433–5.067초.
3. 체험 행동과 대표 시설: 5.067–8.933초.
4. 추가 시설과 이용 편익: 8.933–13.233초.
5. 감각을 정서적 보상으로 연결: 13.233–18.400초.
6. 저장과 미래 방문 제안: 18.400–20.533초.

이것은 대본의 구조 분석이며 원문 전사나 모방용 문장 목록이 아니다.

## 제작 제안

- 출력은 1080×1920 / 30fps. 약 20개의 입력 영상에서 가장 좋은 짧은 구간을 선택한다.
- 20개 컷을 쓴다면 약 20~26초 편집을 먼저 검토하되 실제 내레이션 길이로 조정한다.
- 기본 전환은 하드 컷. 대표 장면은 충분히 보고, 연결부는 짧게 쓴다.
- 각 컷은 화면상 새 장면이 기본이지만, 초반 핵심 이미지를 후반에 짧게 재등장시키는 의도적 콜백은 허용한다. 반복 컷의 역할은 달라야 한다.
- 영상화는 사진 속 피사체를 움직이기보다 구도를 거의 고정한다. 카메라는 고정이 기본이고, 필요한 경우에만 거의 느껴지지 않는 느린 2D 이동을 쓴다. 편집 리듬은 하드 컷과 자막으로 만든다.
- 커버를 별도 파일로 제공한다. 1프레임 커버 삽입은 레퍼런스의 관측값이며 모든 영상에 의무적으로 복제하지 않는다.
- 여성 TTS를 우선 검토한다는 기존 계정 방향은 참고한다. 실제 음성 제공사·지출·개성은 처음 사용할 때 결정한다.
- 사용자가 정한 계정 페르소나에 맞춘 경험담형 1인칭 말투는 사용할 수 있다. 단, 시설·가격·독점성·포함 혜택은 확인된 사실만 말하고, 출처에 없는 구체적인 개인 사건이나 후기를 사실처럼 만들어내지 않는다.
- 이미지 원본의 크롭·색상 변경 버전을 서로 다른 원본으로 세지 않는다.
- 영상과 자막의 경계는 별개 배열로 저장한다. 실제 TTS에 정렬한 결과와 글자 수 기반 추정값을 구분한다.

## 제작 패키지의 데이터

`property.json`

- `property_id`, 숙소 정식명, 위치, 기준 날짜.
- 주장마다 출처 URL·확인 날짜·객실 유형·공용/개별 시설·확인 상태.
- 예약 프로그램과 상품 URL, 사용자 소유 제휴 URL, 판매 상태 확인 시각.

`sources.json`

- 원본별 `source_id`, 출처 페이지와 이미지 URL, 권한 확인 상태.
- 원본 파일 해시, 원본·세로 파일 크기, 크롭 영역, 피사체·객실 유형.
- 중복 그룹, 텍스트/워터마크 여부, 채택 이유. 크롭으로 표식을 숨겨 사용하는 방식은 채택하지 않는다.

`shot-plan.json`

- `shot_id` 01~20, `source_id`, 장면 역할, 관련 사실 ID, 자막.
- 이미지 파일, 영상화 프롬프트와 제약, 원하는 카메라 방향.
- 생성 영상 파일명, 필요 길이, 사용자 전달·수령 상태.

`edit.json`

- `fps`는 유리수, 해상도, 음성 파일과 정렬 정보의 출처.
- `shots`: 파일, 사용할 원본 시작점, 타임라인 시작·끝 프레임. 끝점은 항상 미포함.
- `captions`: 텍스트, 시작·끝 프레임, 스타일. 장면과 독립.
- 커버 파일, 오디오 믹스 설정, 브랜드 표식, 필요한 고지 설정.
- 렌더링 이력과 최종 파일 검수 결과.

## 단계 상태

`researching → sources_ready → generation_pack_ready → awaiting_user_clips → clips_verified → narration_aligned → edit_ready → rendered → delivered`

각 단계는 파일과 검수 결과가 있어야 이동한다. 이미지 URL 목록만 있으면 `sources_ready`가 아니다. 프롬프트를 만들었다고 영상이 준비된 것은 아니다. 렌더 명령이 성공해도 최종 파일을 확인하기 전에는 `delivered`가 아니다.

## 검수 기준

- 숙소와 객실 유형이 맞고, 대본에서 말한 시설이 해당 컷으로 증명된다.
- 실제 9:16 이미지와 세로 영상이며 반복 원본·원하지 않는 텍스트·검은 프레임·심한 왜곡이 없다.
- 발화와 자막이 맞고 자막 길이 때문에 읽지 못하는 구간이 없다.
- 영상 타임라인은 빈 프레임·겹침 없이 이어지고, 오디오가 잘리거나 끝에 불필요하게 남지 않는다.
- 최종 MP4가 1080×1920, 30fps, H.264/AAC로 재생된다.
- 예약 링크는 올바른 숙소·객실로 연결되며 게시 시점에 유효하다.

## 운영 경로에 대한 관찰

지정 릴스의 링크 허브 18번은 `성신여대 케이브 료칸 호텔 by 아늑 성신여대점`의 쿠팡 상품 `10000011427298`로 연결되었다. 조사 시점에는 상품 판매 종료로 표시되었다. 숙소 폐업 여부는 이 관찰로 판정하지 않는다.

허지니는 복수 예약 제휴 경로를 사용하고, 오하영은 공개 허브에서 쿠팡 제휴를 고지한다. 링크 방문 자체와 제휴 구매 수익을 구분한다. 실제 매출과 자동 DM 제공사는 미확인이다.

후속 DM 구현에는 게시물-숙소-트리거-유효 링크 매핑, 공식 댓글 이벤트, 중복 전송 방지, 결과 기록이 필요하다. Meta의 현재 프로페셔널 계정·권한·Private Replies 조건을 실제 연결 시 확인한다. 이 문서만으로 계정을 연결하거나 메시지를 발송하지 않는다.

## 현재 구현 범위

`tools/analyze_reference.py`는 로컬 원본에서 기술 정보, 장면 후보, 1초 프레임 보드, 경계 앞뒤 검수 보드를 생성한다. 경계 후보는 사람의 시각 검수를 거쳐야 한다. `tools/render_reel.py`는 20개 영상, 컷별 대사, Typecast API 인증을 받아 타임스탬프 TTS·자막 싱크·하드 컷·최종 MP4 렌더링을 수행한다. 이미지/영상 수집기와 DM 운영기는 아직 구현 범위가 아니다.

기존 스타빌 제주 자산은 19개, 모두 1080×1920으로 확인했다. 기존 대본은 같은 자막 밀도로 환산하면 약 36.4초 규모이므로 레퍼런스 길이를 목표로 할 때 축약이 필요하다. 이는 실제 TTS 길이를 측정한 결과가 아니다.
