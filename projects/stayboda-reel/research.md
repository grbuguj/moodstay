# 스테이 보다 — 제작 조사 메모

## 확인할 대표 화면

- 숲속 이끼정원과 창 너머 정원 풍경
- 실내 거실·침실과 통창의 연결
- 정원동/보다동 객실 명칭과 실제 객실 수
- 주방·식탁·데크·욕실 등 편의시설

## 출처

- [STAYFOLIO 스테이 보다 갤러리](https://www.stayfolio.com/en/findstay/stayboda/gallery) — 선택 사진의 출처 페이지. 사진별 직접 원본 URL은 다음 수집 시 `photo_manifest.json`에 기록한다.

## 상태 / 재검증 메모

- 현재 대본은 20컷 초안이며, 게시 전 객실 운영 정보와 각 편의시설을 최신 공식 안내에서 다시 대조한다.
- 수집한 20장의 세로 크롭은 Codex 작업 폴더의 `outputs/stayboda_vertical_20.zip`에 있다. 이 저장소에는 사진 파일을 넣지 않았다.
- 사진의 인스타그램 게시 허락과 공개 GitHub 저장소에 원본/크롭 파일을 재배포할 권리는 별개로 취급한다. 후자는 확인 전까지 미확인 상태로 둔다.
