# 사실·연출 기준

- 내부 식별명: 양평 비바코스테이
- 영상 내 숙소명: 노출 금지
- 사용자 확인 위치 훅: 서울에서 차로 약 30분
- 화면으로 확인된 요소: 삼각형 숙소, 야외 풀, 거실·주방·침실, 바비큐, 불멍, 투명 찜질 돔
- 중요 정정: 바비큐는 삼각형 숙소 공간에서 하고, 투명 돔은 찜질 돔이다. 둘을 같은 시설처럼 말하지 않는다.
- 금지된 억지 콘셉트: 당일치기, 1박 강조, 동행자 갈등, `A프레임` 같은 내부 제작 용어
- 인물 사용: 장소가 주인공. 필요한 경우에만 얼굴 없는 1인칭 손·발 일부를 제한적으로 사용한다.
- 권리 상태: 실제 사진·생성 영상의 GitHub 재배포 권리는 확인되지 않았으므로 파일은 저장소에서 제외한다.
